# G30 VESC compatibility source audit (2026-10-21)

Scope: code inspection only. **No motor test, hardware validation, build, IAP flashing, bootloader or recovery change performed.** Confirmed FO7x IAP experience is the reference; it must not be equated with qualification of a different application image.

## Verified code facts
- `common_files/src/VescCommand.c`: G30-specific dispatcher handles FW_VERSION, GET_VALUES (+SELECTIVE), SET_CURRENT, SET_CURRENT_BRAKE, SET_MCCONF, GET_MCCONF, DETECT_APPLY_ALL_FOC, APP_DISABLE_OUTPUT and ALIVE.
- G30 `COMM_DETECT_APPLY_ALL_FOC` invokes an RTOS worker; measures R/L and flux; derives current PI and observer gain, stores configuration; no hardware proof for this exact integration.
- App configuration commands (`COMM_GET_APPCONF`, `COMM_SET_APPCONF`) and several other upstream VESC commands are absent from the G30 compact switch; *full* VESC Tool compatibility must not be claimed.
- `common_files/src/g30_sensorless.c`: normal PWM start requires valid motor parameters and rolling/BEMF lock, with separate open-loop detection mode. Thus no normal torque from complete standstill via this code path; kick-start is expected.
- `common_files/src/app_uartcomm.c`: native ADC controller provides brake priority when `ADC_CTRL_TYPE_CURRENT_NOREV_BRAKE_ADC` is selected.
- `common_files/src/g30_recovery_iap.c`: recovery exists inside application, not independent of its boot sequence. No changes made.
- `common_files/src/VescToSTM.c`: corrected existing temp-derating typo using battery cutoff endpoint instead of temperature cutoff endpoint. Must verify via build and controlled thermal simulation.

## Change policy
No speculative flash restrictions, magic boot CRC checks, additional lockouts, bootloader edits or IAP mechanism changes. Existing recovery documentation remains unchanged.
## Agreed motor-start requirements (2026-10-21)
- **Normal riding:** push the scooter to approximately **3 km/h**, then apply throttle. The firmware shall use passive BEMF/rolling detection to acquire rotor position; no self-start from a complete stop is required for normal riding.
- **VESC Tool FOC Detect All only:** permit controlled active open-loop spin from a standstill as required to measure R/L/flux. Detection must remain distinct from normal throttle-based drive.
- **Code observation:** `G30SL_PreparePwmStart()` already bypasses rolling lock during `open_loop` and otherwise requires rolling lock plus valid motor parameters. `G30SL_Configure()` derives `min_speed_unit` from 3 km/h, pole count, and wheel diameter, but clamps to [60,1000]; verify actual wheel speed/pole semantics and BEMF lock on hardware before claiming an exact 3 km/h trigger.
- **Acceptance tests:** (1) no normal drive torque at rest; (2) kick/push above ~3 km/h, then throttle engages smoothly; (3) FOC Detect All can rotate a stationary *free* wheel on current-limited bench supply, with abort and result validation; (4) no automatic movement outside explicitly requested detection.
- No change to existing motor-start code in this documentation-only update; preserve the proven behavior until test results justify a change.
